# Family Asset Map for Codex

This package contains one family-map skill and an OAuth-protected HTTP MCP connection at https://familyassetmap.com/mcp. Install it from the familyassetmap marketplace in Codex. Complete FAM sign-in and read/write consent in the browser; never paste an email code or passphrase into chat.

Ask for a summary or a specific requested institution change. Only your own Standard map is supported. No balances, bank access, sharing, deletion or E2EE edits are exposed. Standard data can be decrypted by FAM; data read by your agent goes to its AI provider.

Connections expire after up to seven days. Revoke access at https://familyassetmap.com/connected-apps independently of uninstalling the plugin.

Installation, validation status and generic MCP setup: https://github.com/lukeon2/familyassetmap-agents
